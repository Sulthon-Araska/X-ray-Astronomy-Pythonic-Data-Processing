# Glossary

This glossary collects the main scientific and technical terms used across this repository and its notebooks.

| Term | Definition |
| --- | --- |
| ARF (Auxiliary Response File) | A calibration file that describes the effective collecting area of an X-ray instrument as a function of energy. |
| Barycentric Correction | A time correction that converts photon arrival times to a common Solar System reference frame for accurate timing analysis. |
| CALDB (Calibration Database) | A mission calibration database used by analysis tools to apply up-to-date instrument calibrations. |
| Counts | The number of detected X-ray photons in a given time bin, detector region, or energy range. |
| Energy Band | A selected interval of photon energies (for example in keV) used for imaging, timing, or spectral extraction. |
| EPIC-pn | The pn camera of XMM-Newton’s European Photon Imaging Camera (EPIC) instrument suite. |
| Event List | A table of detected photon events that stores quantities such as time, energy channel, and detector coordinates. |
| FITS (Flexible Image Transport System) | The standard astronomy file format used for images, tables, spectra, and metadata in this project. |
| FPMA / FPMB | NuSTAR’s two focal plane modules (detectors), commonly processed separately and then combined. |
| FRACEXP | The fractional exposure per time bin, indicating what fraction of the nominal bin duration was actually observed. |
| GTI (Good Time Interval) | Time intervals that pass filtering criteria and are considered valid for scientific analysis. |
| HEASARC | NASA’s High Energy Astrophysics Science Archive Research Center, a core archive and reference source for X-ray mission data. |
| ICRS | The International Celestial Reference System used as a standard celestial coordinate frame. |
| Light Curve | A time series showing how source brightness (count rate) changes with time. |
| NuSTAR | NASA’s Nuclear Spectroscopic Telescope Array mission for high-energy X-ray observations. |
| Observation ID (ObsID) | A unique identifier assigned to each mission observation and used to organize processing products. |
| PHA (Pulse Height Amplitude) | A binned spectrum format representing detected counts per detector channel or energy bin. |
| PSD (Power Spectral Density) | A timing-analysis quantity that describes variability power as a function of temporal frequency. |
| RMF (Redistribution Matrix File) | A calibration matrix describing how true photon energies are redistributed into measured detector channels. |
| SAS (Science Analysis System) | The standard XMM-Newton software suite used for calibration and scientific data reduction. |
| Spectral-timing Analysis | Joint analysis of spectral (energy-dependent) and timing (variability-dependent) properties of an X-ray source. |
| Spectrum | The distribution of detected photon counts as a function of energy. |
| X-ray Astronomy | The study of astronomical sources through X-ray radiation emitted by high-energy astrophysical processes. |
| XMM-Newton | ESA’s X-ray Multi-Mirror Mission used for imaging, spectral, and timing studies of cosmic X-ray sources. |
| XRONOS | A classic high-energy astrophysics timing-analysis package for light curves and variability products. |
| XSPEC | A widely used software package for fitting and interpreting X-ray spectra with physical or phenomenological models. |
